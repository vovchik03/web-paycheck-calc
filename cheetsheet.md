Що згадати з API

document.getElementById(...) — повертає елемент або null
.addEventListener('click', функція) на кнопці
.value в інпута — завжди рядок, навіть якщо там цифри
parseFloat(...) vs Number(...) — вони поводяться по-різному з "12abc" і з "". Перевір обидва в консолі, різниця важлива саме для твого випадку
Number.isFinite(...) — щоб відсіяти NaN
.toFixed(2) — округлення до копійок, повертає рядок
.textContent для запису в <output>
